# Word Filter — 웹페이지 단어 필터링 크롬 익스텐션

등록한 **텍스트 또는 정규표현식**을 웹페이지에서 찾아, **블록** 또는 **단어** 단위로 지정한
컬러로 덮는 Manifest V3 크롬 확장 프로그램입니다. 엘리먼트를 제거하지 않으므로 페이지
레이아웃은 그대로 유지됩니다.

---

# 설치 및 사용 방법

## 1. 설치

1. 크롬에서 `chrome://extensions` 로 이동
2. 오른쪽 위 **개발자 모드** 를 켠다
3. **압축해제된 확장 프로그램을 로드** 클릭
4. 압축을 푼 뒤 **`word-filter-extension` 폴더**(`manifest.json` 이 들어 있는 폴더)를 선택
5. 설치가 끝나면 설정 화면이 자동으로 한 번 열린다

> zip 파일 자체를 선택하면 안 됩니다. 압축을 푼 **폴더**를 선택하세요.

설정 화면을 다시 열려면 확장 아이콘 클릭 → **전체 설정 열기**, 또는
`chrome://extensions` → Word Filter → **세부정보** → **확장 프로그램 옵션**.

설정 화면은 위에서부터 **필터링 패턴 · 미리보기 · 공통 설정 · 필터링 모드 · 필터링 컬러 ·
사이트 예외 · 백업 및 복원** 순서입니다. 맨 위 미리보기는 예시 문장 3줄에 각각 지정된 단어
(**결말 · 스코어 · 예고편**)를 현재 모드와 컬러로 처리해 보여 줍니다. 등록한 패턴과는
무관하므로, 패턴을 등록하지 않은 상태에서도 설정 결과를 바로 확인할 수 있습니다.

설정을 바꾸면 **새로고침 없이** 열려 있는 모든 탭에 즉시 반영됩니다.

화면 오른쪽 위 **테마** 에서 `시스템` · `라이트` · `다크` 중 하나를 고릅니다.

- `시스템` (기본) — 크롬의 모양 설정을 따릅니다. `chrome://settings/appearance` 의 `모드` 를
  바꾸면 즉시 반영되고, `기기 설정 사용` 이면 운영체제 설정을 따릅니다.
- `라이트` · `다크` — 크롬 설정과 무관하게 고정합니다.

선택은 저장되어 **설정 화면 · 팝업 · 패턴 편집 페이지에 함께 적용**됩니다. 웹페이지에 적용되는
필터링 컬러는 테마와 무관하게 직접 지정한 값을 그대로 씁니다.

다음 위치에서는 동작하지 않습니다.

- `chrome://` 페이지, 크롬 웹스토어, PDF 뷰어 (크롬 정책)
- `contenteditable` 영역과 `<input>` / `<textarea>` 의 값 (입력 방해 방지)
- Shadow DOM 내부(closed shadow root)와 cross-origin iframe 내부 (일반 iframe 은 각각 처리됩니다)

## 2. 필터링 패턴 등록

패턴은 항목마다 **매칭 방식**을 따로 고릅니다.

| 방식 | 동작 | 예 |
| --- | --- | --- |
| **텍스트** | 부분 문자열 포함 검사 | `결말` → "결말 주의"가 있는 문단도 처리 |
| **정규식** | 정규표현식 검사 | `\d+화` → "12화", "3화" 모두 처리 |

```
텍스트   결말            부분 일치
텍스트   C++             메타문자가 있어도 문자 그대로 매칭
정규식   결말|스포일러    여러 단어를 한 항목으로
정규식   \d+화           숫자 + "화"
정규식   ^\[광고\]        줄 맨 앞의 [광고] 만
정규식   시즌\s?\d+       "시즌2", "시즌 3" 모두
```

- 등록한 패턴 목록은 매칭 방식 탭 오른쪽의 **`패턴 편집`** 버튼을 눌러 별도 페이지에서 봅니다.
  그 페이지에서도 **같은 추가 폼**으로 패턴을 넣을 수 있고, **검색창**으로 원하는 패턴을 찾아
  삭제할 수 있습니다. 두 화면은 서로 즉시 반영됩니다.
- 정규식은 **입력하는 동안 문법을 검사**합니다. 오류가 있으면 메시지가 뜨고 추가 버튼이 잠깁니다.
- 플래그는 자동으로 붙습니다. 항상 `g`, "대소문자 구분"이 꺼져 있으면 `i` 가 함께 적용됩니다.
- 편집 페이지에서 텍스트 패턴은 먹칠되어 있고, 마우스를 올리면 확인할 수 있습니다.
  정규식은 읽고 고쳐야 하는 값이라 그대로 표시됩니다.
- 패턴은 최대 **100개**, 하나당 **200자**까지 등록할 수 있습니다.
- 부분 일치이므로 짧은 텍스트를 등록하면 과하게 잡힙니다. (예: `이` → 대부분의 문단이 처리됨)
- 정규식에 `(a+)+$` 처럼 중첩 수량자를 쓰면 페이지가 매우 느려질 수 있습니다. 느려지면 해당
  패턴을 삭제하거나 `필터링 사용` 을 끄면 즉시 복구됩니다.

## 3. 사이트 예외

특정 사이트에서만 필터링을 끄고 싶을 때 씁니다. 등록한 도메인에서는 스캔도 감시도 하지
않으므로 페이지가 원래대로 보입니다.

- 주소 전체를 붙여 넣어도 되고 도메인만 적어도 됩니다.
  `https://gall.dcinside.com/board/lists/?id=x` → `gall.dcinside.com` 으로 저장됩니다.
- **하위 도메인도 함께 제외**됩니다. `example.com` 을 등록하면 `blog.example.com` 도 제외됩니다.
  반대로 `blog.example.com` 만 등록하면 `example.com` 은 제외되지 않습니다.
- 앞의 `www.` 는 떼고 저장합니다. `www.example.com` 과 `example.com` 이 갈라지지 않습니다.
- 뒷부분만 같은 다른 사이트는 걸리지 않습니다. `example.com` 등록 시 `evil-example.com` 은 그대로 필터링됩니다.
- 목록에 추가하거나 삭제하면 **열려 있는 탭에 즉시 반영**됩니다.
- 최대 100개까지 등록할 수 있습니다.

예외 사이트에서 확장 아이콘을 누르면 팝업에 그 사실이 표시됩니다. 처리 개수가 0인 이유가
필터링 실패가 아니라 예외 등록 때문임을 알 수 있습니다.

## 4. 필터링 모드

| 모드 | 처리 범위 | 이럴 때 |
| --- | --- | --- |
| **블록** (기본) | 패턴이 걸린 블록 엘리먼트(문단·카드·목록 항목) 전체 | 그 항목 자체를 안 보고 싶을 때 |
| **단어** | 걸린 부분만 | 문맥은 읽으면서 특정 단어만 가리고 싶을 때 |

- **블록 모드는 화면에 보이는 문장 전체로 판정합니다.** 제목과 말머리가
  `<a>제목</a><b>(펌)</b>` 처럼 여러 태그로 나뉘어 있어도 이어 붙인 `제목(펌)` 에서 패턴을
  찾습니다. 그래서 `(펌)` 은 물론 `제목(펌)` 이나 `\(펌\)$` 같은 패턴도 항목 전체를 가립니다.
  들여쓰기와 줄바꿈은 무시하므로 `^` `$` 앵커가 보이는 문장 기준으로 동작합니다.
- 두 모드 모두 **시각적으로만** 가립니다. 텍스트는 DOM 에 남아 `Ctrl+F` 검색이나 복사로
  접근할 수 있고, 마우스 이벤트도 그대로 받습니다.
- **단어 모드**는 텍스트를 `<span>` 으로 감싸므로, 자체 스크립트가 DOM 구조를 가정하는 극소수
  사이트에서 충돌할 수 있습니다. 그럴 때는 블록 모드를 쓰세요.
- **블록 모드**에서 페이지가 ID 셀렉터 + `!important` 로 색을 강제하면 자손 색이 덮이지 않을
  수 있습니다. 이때는 Opacity 를 `0` 으로 두면 대상 전체가 투명해져 문제가 없습니다.

## 5. 필터링 컬러

두 모드가 같은 컬러를 공유합니다. **RGB**(기본 0, 0, 0)와 **Opacity**(기본 1)로 지정합니다.

글자색과 배경색을 같은 값으로 맞추기 때문에 **원문 텍스트는 Opacity 와 무관하게 항상
가려집니다.** Opacity 는 "덮은 색을 얼마나 보여줄지"만 결정합니다.

```
Opacity 1    → 지정한 RGB 로 꽉 찬 블록 (기본값)
Opacity 0.5  → 반투명한 색 블록
Opacity 0    → 완전 투명. 대상이 아예 보이지 않음
```

- 색상 상자를 눌러 고르거나 R/G/B 값을 직접 입력할 수 있습니다. 0~255 를 벗어난 값은
  저장 시 자동으로 잘립니다.
- `기본값으로` 버튼으로 RGB 0,0,0 / Opacity 1 으로 되돌립니다.
- 컬러 칩의 체크 무늬 배경은 Opacity 가 낮을 때 투명해지는 정도를 눈으로 보기 위한 것입니다.

## 6. 팝업 (확장 아이콘 클릭)

- **사용 on/off 토글** — 제목 오른쪽. 즉시 전환됩니다
- 이 페이지에서 처리한 개수 (블록 모드는 블록 수, 단어 모드는 단어 수)
- **필터링 모드 전환** — `블록` / `단어` 를 눌러 바로 바꿉니다
- 현재 컬러 스와치와 `rgba(...)` 값
- **단어 추가 (텍스트)** — 입력하고 `추가`
- **정규식 추가** — 입력하는 동안 문법을 검사하고, 오류면 추가 버튼이 잠깁니다
- `지금 다시 적용` — SPA 처럼 화면이 바뀌었는데 반영이 안 될 때 수동으로 전체 재적용

확장 아이콘의 **배지 숫자** = 그 페이지에서 처리한 개수입니다.

## 7. 백업 및 복원

설정 화면 **맨 아래** 패널입니다. **패턴 · 사이트 예외 · 필터링 모드 · 컬러 · 대소문자 구분**을
한 파일에 담습니다.

`설정 백업 저장` 을 누르면 `word-filter-settings-날짜.json` 이 내려받아집니다.

```json
{
  "format": "word-filter-settings",
  "formatVersion": 1,
  "exportedAt": "2026-07-30T12:34:56.789Z",
  "settings": {
    "isFilteringEnabled": true,
    "filteredPatternList": [ { "pattern": "결말", "matchType": "text" } ],
    "filteringMode": "word",
    "filterColor": { "red": 200, "green": 30, "blue": 60, "opacity": 0.65 },
    "shouldMatchCaseSensitively": false,
    "excludedSiteList": ["example.com"]
  }
}
```

`백업 파일로 복원` 은 현재 설정을 파일 내용으로 **전부 덮어씁니다.** 되돌릴 수 없으므로
확인 창이 한 번 뜹니다.

- 일부 항목만 적어 둔 파일도 받습니다. 빠진 항목은 기본값으로 채워집니다.
- `filteredPatternList` 는 `["결말", "스포일러"]` 처럼 문자열 목록으로 적어도 됩니다.
  텍스트 타입으로 등록됩니다.
- 파일이 잘못되면 오류 메시지가 뜨고 기존 설정은 그대로 유지됩니다.

## 8. 새 버전 파일로 교체하기

| 방식 | 설정 |
| --- | --- |
| **같은 폴더**에 파일만 덮어쓰고 새로고침(↻) | 유지됩니다 |
| **다른 폴더**에 풀어서 새로 로드 | 접근할 수 없습니다 (확장 ID 가 폴더 경로에서 파생되므로) |
| 확장을 제거하고 다시 로드 | 저장 데이터도 함께 지워집니다 |

같은 폴더에 덮어쓰는 방식이 가장 안전합니다. 폴더를 옮기거나 확장을 제거해야 한다면
**그 전에** `설정 백업 저장` 으로 파일을 내려받고, 새로 로드한 뒤 `백업 파일로 복원` 하세요.

# 테스트 방법

## 1. 테스트 페이지 띄우기

확장은 `http` / `https` 페이지에서만 동작합니다. `file://` 로 직접 열면 아무 일도
일어나지 않으므로 로컬 서버로 띄우세요.

```bash
cd test
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/test-page.html` 접속.

설정 화면에서 **`스포일러`, `결말`, `spoiler`** 3개를 **텍스트**로 등록합니다.

## 2. 블록 모드 — 섹션 1~8

**필터링 모드 → 블록**, **Opacity 1**(기본값) 상태로 확인합니다. 대상은 검은 블록으로 덮입니다.

| # | 섹션 | 기대 결과 |
| --- | --- | --- |
| 1 | 문단 | 패턴이 있는 `<p>` 만 가려지고 다른 문단은 그대로 |
| 2 | inline(span) | inline 인 `<span>` 대신 상위 `<p>` 가 가려짐 |
| 3 | 목록 | 해당 `<li>` 하나만 가려지고 목록 구조는 유지 |
| 4 | 카드 / 중첩 | 카드 `<div>` 단위로 가려지고 섹션 전체는 남음 |
| 5 | 표 | 해당 `<td>` 만 가려지고 표 골격은 유지 |
| 6 | 대소문자 | 구분 OFF → 두 줄 모두 가려짐 / ON → 등록한 형태와 일치하는 줄만 |
| 7 | 동적 DOM · 텍스트 변경 | **"스포일러 카드 추가"** → 새로고침 없이 즉시 가려짐 / **"텍스트를 결말로 변경"** → 기존 카드가 즉시 가려짐 |
| 8 | 지연 로딩 | 페이지 로드 3초 뒤 자동 추가되는 카드가 가려짐 |

## 3. 패턴 편집 페이지

| 순서 | 확인할 것 |
| --- | --- |
| 1 | 설정 화면 `필터링 패턴` 에 목록이 보이지 않고 개수만 표시되는지 |
| 2 | 매칭 방식 탭 오른쪽의 `패턴 편집` 버튼 클릭 → 새 탭에서 편집 페이지가 열리는지 |
| 3 | 버튼을 다시 눌러도 탭이 새로 쌓이지 않고 기존 탭이 재사용되는지 |
| 4 | 편집 페이지에 등록한 패턴이 타입 배지(TEXT/REGEX)와 함께 모두 보이는지 |
| 5 | 편집 페이지의 **필터링 패턴** 폼으로 추가 → 아래 목록에 즉시 나타나는지 |
| 6 | 편집 페이지에서 `(abc` 입력 → 설정 화면과 같이 오류가 뜨고 추가 버튼이 잠기는지 |
| 7 | **검색창**에 일부 글자를 넣으면 해당 패턴만 남고 `N개 / 전체 M개` 로 표시되는지 |
| 8 | 검색 결과가 없으면 안내가 뜨고, `지우기` 로 전체 목록이 돌아오는지 |
| 9 | 편집 페이지에서 삭제 → 설정 화면의 개수 표시가 함께 줄어드는지 |
| 10 | 설정 화면에서 추가 → 편집 페이지 목록에 즉시 나타나는지 |

## 4. 단어 모드 — 섹션 9

**필터링 모드 → 단어** 로 바꿉니다. 새로고침 없이 즉시 전환되고,
섹션 1~8 의 블록 처리가 풀리면서 단어 처리로 교체되는지도 함께 확인하세요.

| 케이스 | 기대 결과 |
| --- | --- |
| 문장 중간 단어 | 단어만 덮이고 앞뒤 문맥은 그대로 읽힘 |
| 한 줄에 2회 등장 | 두 곳 모두 처리됨 |
| 링크 안의 단어 | 링크 텍스트 중 해당 단어만 덮임 |
| `color: !important` 강제 | 페이지 CSS 를 이기고 덮임 |
| 그라데이션 텍스트 | 글자가 드러나지 않음 |
| 줄바꿈에 걸치는 긴 단어 | 양쪽 줄 모두 덮임 |
| `<input>` / `contenteditable` | **처리되지 않음** (의도된 동작) |

## 5. 필터링 컬러 — 섹션 10

**필터링 모드 → 블록** 으로 두고 Opacity 를 `1 → 0.5 → 0` 으로 내려 봅니다.

| 케이스 | 기대 결과 |
| --- | --- |
| Opacity 1 / 0.5 / 0 | 꽉 찬 색 블록 → 반투명 색 블록 → 완전 투명. 어느 값에서도 원문 글자는 안 읽힘 |
| 자식이 자기 색을 가진 카드 | Opacity 1 에서 초록·주황 글자까지 모두 덮임 |
| 이미지가 있는 카드 | Opacity 1 에서 이미지도 감춰짐 |
| 링크 색·밑줄 | 링크 색과 밑줄 색까지 함께 덮임 |
| 원래 `opacity: 0.85` 인 카드 | 필터를 끄면 0.85 가 정확히 복원됨 |
| RGB 변경 | `200, 30, 60` 등으로 바꾸면 즉시 그 색으로 바뀜 |

## 6. 정규표현식 — 섹션 11

**매칭 방식 → 정규식** 으로 아래 4개를 등록하고, **단어 모드**로 확인합니다.

```
\d+화        ^\[광고\]        시즌\s?\d+        SPOILER
```

| 케이스 | 기대 결과 |
| --- | --- |
| `12화 예고편` | `12화` 만 덮임 |
| `3화 그리고 25화` | 한 줄에서 두 곳 모두 덮임 |
| `화요일 연재입니다` | 숫자가 없어 매칭 안 됨 |
| `[광고] 지금 구매` | `^` 앵커 일치 → 덮임 |
| `본문 중간의 [광고]` | `^` 앵커 불일치 → **처리되지 않음** |
| `시즌2` / `시즌 3` | `\s?` 로 둘 다 덮임 |
| `SPOILER`/`Spoiler`/`spoiler` | 대소문자 구분 OFF → 셋 다 / ON → 대문자만 |
| `C++` 를 정규식으로 등록 | 문법 오류로 거부되고 오류 메시지 표시 |
| `(abc` 입력 중 | 추가 버튼이 잠기고 오류 메시지 표시 |

## 7. 백업 및 복원

설정 화면 맨 아래 `백업 및 복원` 패널에서 확인합니다.

| 순서 | 확인할 것 |
| --- | --- |
| 1 | 모드·컬러·대소문자·패턴을 기본값과 다르게 바꾼 뒤 `설정 백업 저장` |
| 2 | 내려받은 파일의 `settings` 안에 5개 항목이 모두 들어 있는지 확인 |
| 3 | 설정을 전부 다르게 바꾼 뒤 `백업 파일로 복원` → 확인 창에서 확인 → 1번 상태로 복구 |
| 4 | 복원 직후 설정 화면의 값(RGB·모드 등)도 함께 갱신되는지 확인 |
| 5 | 확인 창에서 **취소** → 현재 설정이 그대로 유지되는지 확인 |
| 6 | JSON 이 아닌 파일 / `[1,2,3]` 같은 파일로 복원 → 오류 메시지, 기존 설정 유지 |
| 7 | `{"filteringMode":"word"}` 만 담긴 파일로 복원 → 모드만 바뀌고 나머지는 기본값 |
| 8 | `{"filteredPatternList":["속보"]}` 로 복원 → 텍스트 타입으로 등록 |

## 8. 라이트 / 다크 테마 자동 전환

설정 화면 오른쪽 위 `테마` 선택과 `chrome://settings/appearance` → `모드` 를 함께 확인합니다.
확장을 새로고침할 필요 없습니다.

| 순서 | 확인할 것 |
| --- | --- |
| 0 | `테마` 를 `라이트` / `다크` 로 바꾸면 즉시 전환되고, 팝업·패턴 편집 페이지도 같은 테마인지 |
| 0-1 | `테마` 를 `시스템` 으로 되돌리면 크롬 설정을 다시 따르는지 |
| 1 | `테마`=`시스템` 상태에서 크롬 `모드` 를 `라이트` → `다크` 로 전환 → 색이 즉시 바뀌는지 |
| 2 | 다크에서 본문·보조 텍스트가 또렷하게 읽히는지 |
| 3 | 먹칠 바 · 선택된 모드 타일 · 기본 버튼이 배경과 구분되는지 |
| 4 | 슬라이더 · 색상 상자 · 숫자 입력 · 파일 선택 버튼이 함께 어두워지는지 |
| 5 | 미리보기와 컬러 칩의 체크무늬가 배경에 묻히지 않는지 |
| 6 | 정규식에 `(abc` 를 입력해 오류 메시지가 읽히는지 |
| 7 | 팝업(확장 아이콘 클릭)도 같은 테마로 보이는지 |
| 8 | `모드` 를 `기기 설정 사용` 으로 두고 OS 테마를 바꿔도 따라오는지 |
| 9 | **웹페이지의 필터링 결과는 테마와 무관하게** 지정한 컬러 그대로인지 |

## 9. 여러 태그로 나뉜 제목 (블록 모드)

게시판 목록처럼 제목과 말머리가 다른 태그에 들어 있는 구조를 확인합니다.

```html
<td><a>부산 ARS 투표 안내!</a><b>(펌)</b></td>   <!-- 화면: 부산 ARS 투표 안내!(펌) -->
```

**필터링 모드 → 블록** 으로 두고 아래를 각각 등록해 봅니다. 넷 다 **행 전체**가 가려져야 합니다.

| 패턴 | 방식 |
| --- | --- |
| `(펌)` | 텍스트 |
| `안내!(펌)` | 텍스트 — 두 태그에 걸친 문자열 |
| `\(펌\)$` | 정규식 — 끝나는 문장 |
| `^부산.*\(펌\)$` | 정규식 — 전체 일치 |

같은 목록의 **다른 행은 그대로** 남아야 하고, 표 전체가 가려지면 안 됩니다.

## 10. 사이트 예외

| 순서 | 확인할 것 |
| --- | --- |
| 1 | 필터링이 동작하는 사이트에서 주소를 복사해 `사이트 예외` 에 붙여 넣고 추가 |
| 2 | 목록에 도메인만(경로·`www.` 제외) 저장되는지 확인 |
| 3 | 그 탭으로 돌아가면 **새로고침 없이** 필터링이 풀려 있는지 |
| 4 | 확장 아이콘 클릭 → 팝업에 예외 안내가 뜨는지 |
| 5 | 같은 사이트의 하위 도메인 페이지도 제외되는지 |
| 6 | 다른 사이트에서는 그대로 필터링되는지 |
| 7 | 예외를 삭제하면 즉시 다시 필터링되는지 |
| 8 | `설정 백업 저장` 파일의 `excludedSiteList` 에 목록이 들어 있는지 |

## 11. 팝업 단축 메뉴

확장 아이콘을 클릭해 확인합니다.

| 순서 | 확인할 것 |
| --- | --- |
| 1 | 제목 `WORD FILTER` 오른쪽에 사용 토글이 있고, 끄면 즉시 필터링이 풀리는지 |
| 2 | `모드` 줄의 `블록` / `단어` 를 눌러 모드가 바뀌고 페이지에 즉시 반영되는지 |
| 3 | 모드를 바꾸면 개수 캡션이 `처리한 블록` ↔ `처리한 단어` 로 함께 바뀌는지 |
| 4 | `단어 추가` 로 넣은 항목이 설정 화면에 **텍스트** 타입으로 들어가는지 |
| 5 | `정규식 추가` 에 `(abc` 를 입력 → 오류 메시지가 뜨고 추가 버튼이 잠기는지 |
| 6 | `\d+화` 로 고치면 잠금이 풀리고, 추가하면 **정규식** 타입으로 들어가는지 |
| 7 | 예외 사이트에서 열면 예외 안내가 뜨는지 |

## 12. 실제 사이트에서 확인

1. 뉴스나 커뮤니티 사이트에서 흔한 단어(예: `속보`)를 등록
2. 확장 아이콘의 배지 숫자가 그 페이지에서 처리한 개수와 맞는지 확인
3. 팝업에서 필터링을 끄면 즉시 원래대로 돌아오는지 확인
4. 무한 스크롤로 새 글을 불러와도 계속 처리되는지 확인

## 13. 처리 여부를 확인하는 방법

- **눈으로**: 기본값 Opacity `1` 에서는 처리된 대상이 색 블록으로 명확히 보입니다.
  (Opacity 를 `0` 으로 내리면 완전히 투명해져 "안 보이는 것"이 정상이므로 눈으로 구분하기 어렵습니다.)
- **DevTools**: F12 → Elements 에서 아래 속성을 찾습니다.

  | 속성 | 의미 |
  | --- | --- |
  | `data-word-filter-block="true"` | 블록 모드로 처리한 엘리먼트 |
  | `data-word-filter-word="true"` | 단어 모드로 삽입한 `<span>` |
  | `data-word-filter-matched-word` | 처리를 유발한 패턴 (정규식이면 정규식 원문) |
  | `data-word-filter-original-opacity` | 블록 처리 전 원래 인라인 opacity |
  | `--word-filter-color` | 적용된 RGB 값 |

- **콘솔에서 개수 세기**:

  ```js
  document.querySelectorAll('[data-word-filter-block]').length; // 처리한 블록
  document.querySelectorAll('[data-word-filter-word]').length;  // 처리한 단어
  ```

## 14. 복원 확인

1. 패턴을 삭제하거나 모드를 바꾸거나 "필터링 사용"을 끈다
2. 블록 처리가 풀리고, 단어 `<span>` 은 원래 텍스트 노드로 되돌아간다
3. `data-word-filter-*` 속성과 `--word-filter-color` 가 모두 사라지고, 빈 `style=""` 도 남지 않는다
4. 페이지가 원래 갖고 있던 인라인 스타일(`opacity: 0.85`, 자식의 `color: red` 등)은 그대로 복원된다

```js
// 복원 후 0 이어야 한다
document.querySelectorAll('[data-word-filter-block],[data-word-filter-word]').length;
```

## 15. 코드를 고친 뒤 다시 테스트할 때

`chrome://extensions` → Word Filter 카드의 **새로고침(↻)** → 테스트 페이지 새로고침.
content script 를 고쳤으면 페이지 새로고침이 반드시 필요합니다.

service worker 로그는 `chrome://extensions` → Word Filter → **Service Worker** 링크에서 봅니다.
설정 화면·팝업 로그는 해당 화면에서 F12 로 봅니다.

고쳐야 할 파일 위치:

```
word-filter-extension/
├── manifest.json
└── src/
    ├── shared/filter_settings_storage.js      설정 저장·검증, 백업/복원
    ├── shared/filter_apply_helper.js          패턴 컴파일, 두 모드의 적용·복원
    ├── shared/theme.css                       테마 팔레트와 공통 컴포넌트 (세 화면 공용)
    ├── shared/theme_preference.js             저장된 테마를 문서에 적용
    ├── shared/pattern_form.js                 패턴 추가 폼 (설정 화면·편집 페이지 공용)
    ├── content/word_filter_content_script.js  DOM 스캔과 감시
    ├── content/word_filter_styles.css         블록 모드 스타일
    ├── background/service_worker.js           아이콘 배지
    ├── options/                               설정 화면
    ├── pattern-editor/                        패턴 편집 페이지
    └── popup/                                 팝업
```
