Word Filter 테스트 페이지

확장 설정에서 스포일러, 결말, Spoiler 를 등록한 뒤 이 페이지를 확인하세요. 섹션 1~8 은 블록 모드, 섹션 9~10 은 단어 모드 및 필터링 컬러, 섹션 11 은 정규표현식 검증용입니다.

1. 문단 (block 엘리먼트)

단어가 있는 <p> 만 사라지고 나머지 문단은 그대로 남아야 합니다.

이 문단에는 걸릴 단어가 없습니다. 그대로 보여야 정상입니다.

이 문단에는 스포일러 라는 단어가 들어 있어 숨겨져야 합니다.

이 문단도 정상적으로 보여야 합니다.

2. inline 엘리먼트 (span)

<span> 은 inline 이므로 상위 block 인 <p> 까지 올라가 숨겨져야 합니다.

앞부분 텍스트 결말 뒷부분 텍스트

이 줄은 남아 있어야 합니다.

3. 목록 (li 단위로 숨김)

단어가 포함된 <li> 하나만 사라져야 합니다.

  • 첫 번째 댓글 — 재미있게 봤습니다
  • 두 번째 댓글 — 결말 진짜 충격적
  • 세 번째 댓글 — 다음 편 기대됩니다

4. 카드 / 중첩 구조

카드 안의 텍스트가 걸리면 카드(div) 단위로 사라지고, 섹션 전체는 남아야 합니다.

공지 서버 점검 안내
주의 스포일러 포함된 글입니다
공지 이벤트 당첨자 발표

5. 표 (td 단위로 숨김)

제목 작성자
일반 게시글 홍길동
결말 정리글 임꺽정

6. 대소문자 구분 테스트

"대소문자 구분"을 끈 상태에서 spoiler 를 등록하면 아래 두 줄 모두 사라집니다. 켜면 정확히 일치하는 줄만 사라집니다.

lowercase: this line contains spoiler text

Uppercase: this line contains Spoiler text

7. 동적으로 추가되는 DOM (MutationObserver 검증)

버튼을 누르면 나중에 추가되는 요소입니다. 새로고침 없이 즉시 숨겨져야 합니다.

이 문장은 버튼을 누르면 내용이 바뀝니다.

8. 3초 후 자동 추가 (지연 로딩 시나리오)

페이지 로드 3초 뒤에 자동으로 카드가 하나 추가됩니다.

9. 단어 모드 검증

설정에서 필터링 모드 → 단어 를 선택하고 필터링 컬러 Opacity 를 1 로 올린 뒤 확인하세요. 단어 위에만 색이 덮이고 나머지 문장은 그대로 읽혀야 합니다.

문장 중간에 결말 이 있어도 앞뒤 문맥은 읽을 수 있어야 합니다.
한 줄에 결말 이 두 번 나오면 결말 둘 다 칠해져야 합니다.
링크 안의 단어도 칠해져야 합니다 → 결말 정리 게시글 보기
페이지가 색을 !important 로 강제한 경우 → 결말 언급 도 칠해져야 합니다.
그라데이션 텍스트(text-fill-color: transparent)에서도 결말 이 드러나지 않아야 합니다.
좁은 폭에서 줄바꿈에 걸리는 경우: 아주긴단어결말테스트문자열 도 끊기지 않고 칠해져야 합니다.
편집 가능 영역입니다. 여기의 결말 은 편집 방해를 막기 위해 제외됩니다.

10. 필터링 컬러 검증 (RGB / Opacity)

필터링 모드 → 블록 으로 두고 Opacity 를 0 → 0.5 → 1 로 올려 보세요. 0 이면 카드가 완전히 사라지고, 1 이면 지정한 RGB 색으로 꽉 찬 블록이 되어야 합니다. 어느 값에서도 원문 글자는 읽히지 않아야 합니다.

자식이 자기 색을 가진 경우 → 결말 언급 있음 (Opacity 1 에서 초록·주황 글자까지 모두 덮여야 합니다)
그라데이션 텍스트에 결말 이 있어도 글자가 드러나지 않아야 합니다.
이미지가 함께 있는 카드의 결말 언급 (Opacity 1 에서 이미지도 감춰져야 합니다)
링크 색과 밑줄도 결말 처리 시 함께 덮여야 합니다
페이지가 원래 opacity: 0.85 를 갖고 있던 카드의 결말 언급. 필터를 끄면 0.85 가 그대로 복원되어야 합니다.

11. 정규표현식 검증

설정에서 매칭 방식 → 정규식 을 고르고 아래 4개를 등록하세요. \d+화 · ^\[광고\] · 시즌\s?\d+ · SPOILER
확인이 쉬우려면 단어 모드 + Opacity 1 로 두세요.

12화 예고편이 공개되었습니다 (숫자+화 매칭)
3화 그리고 25화 동시 공개 (한 줄에 두 번 매칭)
화요일 연재입니다 (숫자가 없어 매칭 안 됨)
[광고] 지금 구매하세요 (^ 앵커 일치)
본문 중간의 [광고] 표기 (^ 앵커 불일치 → 처리 안 됨)
시즌2 방영 시작 (공백 없음)
시즌 3 방영 시작 (공백 있음 — \s? 로 둘 다 매칭)
대소문자: SPOILER / Spoiler / spoiler — "대소문자 구분"을 끄면 i 플래그가 붙어 셋 다, 켜면 대문자만 매칭됩니다.
메타문자 포함 텍스트: C++ 와 (주)회사 를 텍스트 방식으로 등록하면 그대로 매칭되고, 정규식 방식으로 등록하면 문법 오류로 거부됩니다. 항목별 타입이 필요한 이유입니다.
